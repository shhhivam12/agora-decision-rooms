# Current demo script

Use [the current-build video journey](video-demo-journey.md) for the feature inventory, three-minute storyboard, dialogue and exact guided clicks. See [the live demo setup](live-demo-guide.md) for laptop + Android testing.

The current build combines real shared Agora voice and captions with a separate guided Smart Stage. Live voice was reported working by the user on 3 October 2026. The stage uses fixture venues, simulated votes, explicit host approval and an on-screen local receipt. It does not execute a real calendar write or automatically consume live speech.

The earlier golden-path script described planned integrations such as speech-to-card extraction, synchronized votes and a provider-confirmed calendar action. Those are future work and should not appear as implemented features in the final recording.

# Media credits

## Current artwork

Kabir, the recurring cast and the illustrated story scenes are fictional brand artwork created with built-in image generation. The app uses optimized PNG assets on native platforms and WebP assets in the browser. Kabir's live browser avatar is drawn in SVG/CSS; its mouth follows incoming assistant audio.

The product-story cards use actual captures of the app's microphone-free shared Stage, composed with the illustrated cast. Captures include backend member preferences, provider results and votes. The cards do not establish a recorded group call; provider values are dated examples.

The [current thumbnail](assets/video/decision-rooms-youtube-thumbnail-v1.jpg) is generated marketing artwork referencing Kabir, the approved lockup and current Stage UI. It is not an unchanged app screenshot.
